# OS.carbon
Stupid 64-bit OS written in Carbon

To be frank, I have barely any knowledge in 32-bit OSs, let alone 64-bit. Carbon's compiler was asserting on `i686-elf` so I had to ask Gemini and vibecode the process of going into long mode.

The only non-vibecoded part is `kernel/main.carbon`, but even then it's updated example from OSDev wiki.

Made this to see if Carbon *can* make an OS kernel if pushed enough and yes it can, it's still very early. No enums, proper range based for loop, code being difficult to understand, bla bla bla. Enjoy this mess and I'll go cry.
